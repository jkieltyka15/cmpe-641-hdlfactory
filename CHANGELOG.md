# Changelog

## [1.0.0] - 2026-08-28

Initial paper release of HDLFACTORY.

- Natural-language Verilog generation with Ministral-3 (3B).
- Area- and power-oriented optimization with Codestral-22B.
- Five-stage validation pipeline using Verilator and Icarus Verilog.
- Docker Compose deployment with FastAPI, Redis, Ollama, worker, and nginx services.
- Benchmark testbenches and Synopsys DC/ICC2 flow for adder32, alu32, counter8, decoder3x8, and mux4x16.
- Reproducible synthesis reports and logs for draft and final designs.
